# Zariya Approval Workflow

A responsive front-end prototype for Team Zariya's SIH 2026 project: Integrated AICTE Approval Workflow Automation, Compliance Monitoring and Alert Management System.

## Preview

Open `index.html` in a browser. No build step is required.

## Included workflow

- Unified approval operations dashboard and recent audit activity
- Application queue with status filters and case detail views
- Intake and regional routing visibility
- Scrutiny and EVC stages
- Document status tracking
- Deadline alerts and escalation visibility
- Regional compliance summary
- CSV export of the sample queue
- Responsive layout for desktop and mobile

All records, counts, dates and people shown are illustrative sample data. This static prototype does not connect to AICTE systems or implement production authentication, APIs, email delivery or persistent storage.
